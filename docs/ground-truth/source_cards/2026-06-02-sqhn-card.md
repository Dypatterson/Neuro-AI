- **Claim:** A hierarchical, sparse, **quantized** (one-hot per node) tree of Hopfield-like memories that learns **online-continually** with a **purely LOCAL, non-backprop** write rule + **neurogenesis**, matching/beating SoTA on associative-memory/continual tasks. Load-bearing methodological claim (Abstract; p.4-5): SQHN "uses only local learning rules," updating "based solely on information local to the neuron or synapse," contrasted with "all the methods reviewed... use BP in some form." Tested on IMAGE patches (MNIST/EMNIST/CIFAR/TinyImageNet/CalTech256).

- **Mechanism (architecture + the EXACT algorithm):**
  - **Tree** (Fig. 1A): visible leaves clamped to non-overlapping input patches → hidden nodes (each a one-hot categorical `h*_l`) → root "memory/hippocampal" node. One parent per node. Edge l→child = memory matrix `M_{pa_l,l}` (columns = stored prototypes). Energy `E=(1/L)Σ_l p(h*_l|pa_l)` (Eq. 1) — a SUM (neurons sum child+parent, not multiply).
  - **Recall = single FF+FB sweep** (Alg. 1): FF up shifted-cosine (Eq. 14/15), interior `h_l=(1/Z)M_l^T h_c^max` (Eq. 16), root `argmax` (Eq. 17); FB down `h*_l=argmax(λ h_l+(1−λ)M_{pa_l}h*_{pa_l})`, λ=0.5 (Eq. 18). Inference `argmax_h E` (Eq. 2); learning MAP `argmax_θ Σ_t E` (Eq. 3). ONE pass, not iterated descent.
  - **THE LOCAL WRITE RULE (Eq. 4):** `ΔM_{pa_l,j}=(1/(c*_{pa_l}+1))·(h*_l − M_{pa_l,l}h*_{pa_l})·h*_{pa_l}^T`, `c*`=parent-activation count. One-hot `h*_{pa_l}` ⇒ SINGLE-column update (parameter isolation). Code (`Unit.py wt_update`): `dw=(targ−p).t().matmul(z)` under `torch.no_grad()`. **No `.backward()`, no autograd, no global error.**
  - **Per-layer nonlinearity:** hard `argmax→one-hot` every node. **Neurogenesis (Eq. 5):** weights init 0; grow a neuron at node l iff no neuron exceeds decaying `ε=α/(t+α)` (Dirichlet). **Top-down sweep:** Eq. 18, a FIXED energy-ascent step.

- **Is the inter-layer write GENUINELY local + non-backprop (the HAM gap)?** **YES — paper + code confirm** (pre/post-synaptic + count, single edge, no chained δ). This is precisely the local write HAM (`pdf:ham-2021`) lacks. **CAVEAT (shapes the verdict):** Eq. 4 is a DELTA/prediction-error rule = the PCN free-energy gradient up to a scalar (the paper's own **Eq. 9**) — each layer RECONSTRUCTS its node from its PARENT's top-down prediction. Error is single-edge (not backprop) but reconstructive ⇒ a **dominant-mode bias** + it carries a local top-down target, which is exactly the shape [exp77 §2](../../../notes/emergent-codebook/phase-3-multilayer-deflation-precommit.md) names as the inadmissibility line. ⇒ port SQHN's **kwta one-hot as the CAPTURE step + the project's own deterministic upward-only GHA deflation as the residual pass; do NOT thread Eq. 4 through a downward weight.**
