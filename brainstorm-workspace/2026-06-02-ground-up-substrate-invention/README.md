invention round that returned 10) converged on a single diagnosis — *the dead mechanisms were

## The bilateral convergence (WF1 ∩ WF2)

Both ends — mechanism-side and substrate-side — independently arrived at the **same object**:

> A token defined by its **distribution over re-used context-TYPES / slots**, with slot-assignment by a
> **local rule**. king≈queen because they *share slots*, not because a centroid drags them together.

That is **outcome #2 (PRESUPPOSED)**, confirmed from both directions: the mechanisms were substrate
proposals wearing mechanism clothes; the load-bearing hard part is the **adaptive local slot-assignment**
(the step NMF does globally and TEM does via backprop — both banned).

## Two verified findings that reframe the whole arc

1. **The type-collapse diagnosis (verified at `experiments/61:254`, `C += P.t() @ P`).** Every experiment
   in the 121–132 arc reads a code where all of a word's occurrences are **averaged into one vector per
   word-TYPE.** Averaging is a low-pass filter that keeps the shared common-mode and **cancels the
   discriminative residual** — so the "subdominant mode" *location* of paradigmatic structure is a
   **consequence of averaging, not a law of the text.** **Per-occurrence (un-averaged) codes were never
   tried.** This makes the writer-limited-vs-object-limited frontier genuinely **unresolved**: every
   verdict was computed on the collapsed object.

2. **The B-KILL arbiter is structurally hostile to a correct paradigmatic CLASS (verified).** B-KILL
   requires *pair*-specificity and calls class-membership (king near any of queen/prince/monarch)
   "para-set hubness" — the failure mode. But a *class* is a legitimate paradigmatic object. So some
   121–132 nulls may be mis-adjudicated, and **any future class-forming mechanism needs a class-level
   differential control precommitted alongside B-KILL.**

*trajectory* the answer); (3) **time is a loop-counter, not a substrate dimension.**

**The one un-invented direction (the critic's recommendation):**

> A **growing relational-graph substrate whose plastic object is the topology/metric itself**, settling
> by **local diffusion**, generation by **annealed sampling**. Per-occurrence experience adds nodes and
> edges by a local co-activation rule; the energy is a graph-Laplacian/diffusion functional; abstraction
> = **graph communities found by local diffusion settling** (never a global eigenvector — community
> structure is a basin of a *grown topology*, the one object provably outside the fixed-operator single-
> projection bound); bind-vs-bundle = an edge that *persists across contexts* vs one that *decays*. The
> code is a node's *position in a grown graph* — there is no flat type-averaged vector to collapse.

## Novelty audit of the critic's direction (web-grounded)

The critic pitched it as "genuinely new." Honest finding: **new to *this project*, recombination to the
field.** Every component is mature:

- Growing graph from local co-activation → **Growing Neural Gas** (Fritzke 1994), Topology Representing Networks.
- Local diffusion → communities **without a global eigenvector** → **Andersen–Chung–Lang** local PageRank (2006) — strongly local, runtime ∝ community size. (The critic's load-bearing claim is a *real, established result*.)
- Community-as-abstraction learned from **local transitions in the hippocampus** → **Schapiro et al.** (temporal community structure; community membership biases inductive generalization).
- Energy-based memory ↔ generative **sampling** → diffusion models *are* associative memory / modern-Hopfield energy (2023–2025 frontier).

**Closest published synthesis = CSCG (Clone-Structured Cognitive Graph, George et al., Nat. Commun.
2021)** + "Space is a latent sequence" (Sci. Adv. 2024). CSCG already does the *outcome*: learns a graph
from sequences; **"clones" = context-specific copies = the per-occurrence/un-collapse move**; community
detection on its transition matrix recovers modular abstraction; generative; does transitive inference +
schema transfer; hippocampally grounded. **It is the non-backprop cousin of TEM** (which the project
already tested in 124/125/129).

**The precise done/not-done split:**
- **Outcome-level** (clones/un-collapse → community → abstraction → generative, biological): **substantially done — CSCG.** Strong external corroboration that the per-occurrence direction is right.
- **Means-level** (purely *local* learning, explicit *energy*, *grown* topology, *no global optimization*): **not done.** CSCG learns by **EM (global forward–backward)** — admissible-adjacent but a global computation, exactly where this project's anti-homunculus/no-global-mechanism invariant bites. **The local/energy/grown realization is the genuinely-unbuilt thing, and it's the new branch's target.**

## The SR-null relationship (the sharp scientific question)

The project already brushed this family and it nulled: the **successor representation** (Reports 124/125)
*is* graph diffusion (Stachenfeld: SR ≈ Laplacian eigenvectors of the transition graph). **But** SR
nulled in the **fixed, type-collapsed, global-eigenvector** form. The critic's version flips the three
variables the session identified as load-bearing: **per-occurrence nodes**, a **grown** topology, and
**local-diffusion** communities (not a global eigendecomposition). So the falsifiable question for the
new branch:

> **Does grown-per-occurrence-local-diffusion escape the SR null, or re-collapse into it?**

## Continual + multimodal (capability the design affords)

Asked whether continual multimodal learning is possible with this design: **yes, and it's a natural
strength** — *more* natural than the king/queen probe.
- **Continual** by construction (GNG built for streams; structural plasticity/neurogenesis is the known
  answer to catastrophic forgetting; grown > static at equal memory budget; = the SQHN card; relies on
  the project's existing replay/consolidation to stay bounded — the fixed-capacity tension).
- **Multimodal** natural in a graph/energy substrate (cross-modal edge = same local co-activation rule;
  binding-by-synchrony for the oscillator family; sensory→association convergence for the hierarchical
  family; biologically: local-plasticity + local-neuromodulatory-gated cross-modal engrams).
- **Strategic:** multimodal is a candidate *orthogonal discriminative channel* — a source of the king/queen
  signal the text-only type-collapsed code lacks (the user's original multimodal intuition).
- **Caveats (honest):** untested for abstraction (Report 119 is a relevant prior null); needs a multimodal
  *data stream* the project doesn't have; cross-modal binding must be **local** (no CLIP-style global
  contrastive objective = backprop); growth must be bounded by consolidation.
