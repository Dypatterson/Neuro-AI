## The one-paragraph picture

The "28 candidates" across both searches are really **~5 distinct bound-escape mechanisms**
(the completeness critic: TEM/SR/grid is *one idea submitted ~9 times*). There are exactly
**four structural escape-routes** from the subdominant-modes bound: (I) **diagonalize a
*different* operator** (transition/successor) and read its subdominant **eigenbasis**;
(II) **factor structure × content** and recombine by FHRR binding (TEM); (III) **replace linear
averaging with a nonlinear/competitive/whitening demixing** (SFA, k-WTA, assembly cap, NSM);
(IV) **add a coding axis co-occurrence lacks** (order/phase, timescale). **Crucially, both
searches independently picked the SLOWNESS/SUCCESSOR family as the only *principled,
non-circular* escape** — and the critic proved SFA ≡ SR (Sprekeler), so they are **one
eigenproblem**.

## The make-or-break (the critic's deepest finding)

The escape is **not free**: power iteration provably converges to the **dominant** eigenvector
— the collocational mode that *is* the problem. Reaching the **subdominant** paradigmatic modes
requires a subdominant→dominant transform (slowness / whitening / operator-inversion). That
transform is what SFA/SR provide **by construction** — BUT the project's discipline demands the
transform be reachable by a **LOCAL** rule (Bio-SFA's lateral anti-Hebbian whitening), not a
global deflation (= the banned SVD homunculus). **Whether the local whitening actually reaches
the slow modes is the single load-bearing question** — and it is cheaply testable (the faithful
`grow_G` read on the *transformed* operator, NOT the SVD proxy that Report 124 §4 proved is a
contraction artifact).

## The recommended next move — a cheap substrate-free ORACLE TRIAGE (the proven pattern)

All of these are killable/greenlightable **before any substrate build**, exactly as exp63 killed
the flat-code R3 build for ~zero cost. Each oracle reuses the exp63 harness + the gauge-free

Each triages a distinct escape-route:

1. **Oracle B (exp65) — SFA/SR slowness** [Route I/III; the convergent lead]. Build the
   slowness/inverted operator so the paradigmatic axis is *dominant*; verify a **local**
   whitening reaches it via `grow_G` (NOT the SVD proxy). PASS = the principled escape is real

2. **Oracle C — eligibility×surprise re-weighting** [the missing family; cheapest decisive].
   Re-weight each co-occurrence by a surprise/eligibility factor (two-timescale) *before* the
   local `grow_G`, run the gauge-free gate. PASS = surprise-gating drops `corr(cooc,drift)`
   below 0.15 where every un-gated rule failed. **Must show the eligibility×surprise interaction
   beats plain SPPMI** (else collapses to 123).
3. **Oracle D — order-vs-context channel split** [Route IV; ~30 lines]. Does paradigmatic
   structure live in the `Π^k` position channel co-occurrence structurally misses?
4. **Oracle E — TEM transition-slot factorization** [Route II; an afternoon, reuses Oracle B's
