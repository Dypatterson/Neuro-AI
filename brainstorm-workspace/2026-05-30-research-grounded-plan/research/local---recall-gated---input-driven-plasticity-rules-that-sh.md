# Research angle: Local / recall-gated / input-driven plasticity rules that shape attractor basins WITHOUT a controller. I extended the project's rank-1 (contrastive/margin) and rank-2 (predictive/JEPA) objective families by hunting 2024-2026 plasticity-rule literature for WRITE dynamics (not readouts) that carve role-discriminative basins via local rules. Major finding: the corpus already holds the four most on-angle anchors (IDP-Hopfield, recall-gated consolidation, EqProp, predictive-coding AM) but ALL as link_only / non-load-bearing, and one card (PMC11257680) is MISATTRIBUTED. ## Key findings
- (IN-CORPUS) CORPUS MISATTRIBUTION (surface this): card pmc:PMC11257680 is titled 'Aitchison recall-gated plasticity', but the opened primary is Lindsey & Litwin-Kumar 2024, eLife (PubMed 39023518). Mechanism is on-angle and anti-homunculus clean: a long-term store gates which short-term updates it consolidates via a fixed function g(r_STM) of STM-LTM overlap r_STM = w_STM . w*, e.g. g=1 if r_STM>=theta else 0. The gate reads a LOCAL population overlap (measurement of a local dynamic), not an external supervisor, and amplifies SNR by letting reliable (repeatedly-recalled) patterns clear threshold more than spurious one-shot noise. I opened the PMC primary AND verified attribution via search.  <https://pmc.ncbi.nlm.nih.gov/articles/PMC11257680/>
- (IN-CORPUS) Input-Driven Plasticity (IDP), Betteti et al., Science Advances 2025 (= corpus arxiv:2411.05849 / doi:10.1126/sciadv.adu6991, both link_only). Opened arXiv HTML. Rule: input u(t) modulates the matrix to W(u) = (1/N) sum_mu alpha_mu(t) xi^mu (xi^mu)^T with saliency alpha_mu(t) = (xi^mu)^T u(t); larger-overlap memories carve deeper valleys; existence/stability thresholds alpha>1. CRITICAL CAVEAT: this is RETRIEVAL-TIME landscape reshaping driven by the cue, NOT an offline WRITE rule storing role->filler structure. It retrieves the dominant component of a MIXED input where vanilla Hopfield fails. Local-dynamic shape (input drives reweight, no metric-read branch), but does NOT write the missing consolidation structure the diagnosis says is absent.  <https://arxiv.org/html/2411.05849>
- (NEW) BTSP endows HDC/VSA binding with attractor features (bioRxiv 2025.05.15.654220 v2; also Research Square rs-6742959). NEW; not in corpus. Opened abstract-level only (full PDF/HTML 403'd). Claim: one-shot BTSP adds attractor basins to BOUND distributed (HDC/VSA) representations, enabling top-down AND bottom-up UNBINDING WITHOUT supplying the composed representation as cue, plus noise-robust retrieval. Single most on-target external result for the project's deepest defect (reports 065/066: bind k,v has NO key-only basins for ANY operator). MUST be CARDED from primary before load-bearing.  <https://www.biorxiv.org/content/10.1101/2025.05.15.654220v2>
- (NEW) BTSP one-shot weight rule, recurrent-network attractor model (PMC10484462, PLOS Comp Biol 1011139). Opened PMC primary. Rule: w_ij = w_ij + Delta_w, Delta_w = P(1 - w_ij) f_P(Delta_theta) - D w_ij f_D(Delta_theta). The instructive plateau potential (PP) is a GLOBAL gating EVENT triggering the update; per-synapse change depends only on local pre/post eligibility (f_P, f_D over the temporal overlap window). One plateau imprints a pattern as a bump attractor in ONE shot. Local, no external controller. Capacity under sparse coding ~M^2, far above Hopfield 0.138N. Concrete anti-homunculus-clean ONE-SHOT WRITE gated by an instructive event, not a metric-read branch.  <https://pmc.ncbi.nlm.nih.gov/articles/PMC10484462/>
- (NEW) BTSP one-shot CAM with binary synapses (Nature Comms 2024, s41467-024-55563-6). NEW; not in corpus. Could NOT open (Nature paywall); search-level only: a simple BTSP model yields content-addressable memory with binary synapses and one-shot learning, suited to encode memories as attractors. Corroborates one-shot-attractor write independently. Needs primary open before load-bearing.  <https://www.nature.com/articles/s41467-024-55563-6>
- (NEW) Temporal Contrastive Learning through implicit non-equilibrium memory (Falk, Strupp, Scellier, Murugan; Nature Comms 2025, arXiv:2312.17723). NEW; not in corpus. Opened arXiv abstract (full PDF paywalled). Integral feedback in each learning DOF provides an IMPLICIT non-equilibrium memory so a system contrasts free vs clamped behavior under an ALTERNATING (sawtooth) protocol WITHOUT explicitly storing both phases or a controller. Updates local in space and time. De-risks the rank-1 contrastive/EqProp objective by removing the hold-two-phases / construct-the-negative machinery the failed phase3b error_driven_learner needed. Scellier is an EqProp co-author (lineage to corpus arxiv:1602.05179).  <https://arxiv.org/abs/2312.17723>
- (NEW) Single-phase Contrastive Hebbian Learning / Dual Propagation ('Two Tales', Hoier & Zach, ICML 2024, arXiv:2402.08573). NEW; not in corpus. Opened arXiv HTML. Two oppositely-nudged compartments s+ and s- maintained simultaneously: s_k+ = f(W s_bar + alpha W^T(s_{k+1}+ - s_{k+1}-)), s_k- = f(W s_bar - alpha_bar W^T(...)), s_bar = alpha s+ + alpha_bar s-. Contrastive gradient carried by (s+ - s-) in ONE settling pass, fully local, no controller, no phase synchronization. Second independent way to get a contrastive WRITE in a single relaxation -> further de-risks rank-1.  <https://arxiv.org/html/2402.08573v3>
- (NEW) Biologically Plausible Dense Associative Memory with Exponential Capacity (Shafiei Kafraj, Krotov, Latham, 2026; arXiv:2601.00984). NEW; not in corpus. Opened arXiv HTML. Replaces Krotov-Hopfield 2021 winner-take-all power-law with threshold nonlinearity Theta(h_mu - theta) so multiple hidden units fire per memory; all 2^{N_h} binary hidden states become stable fixed points -> exponential capacity, large noise-tolerant basins. IMPORTANT CORRECTION vs title: the learning rule (Eq.17, reconstruction argmin over all memories, = Radhakrishnan 2020) is NOT local; the authors explicitly DEFER a biologically-plausible local rule as future work. Relevance: addresses the live capacity-wall / 1-over-sqrt-D crosstalk-floor confound (reports 058, 065) -- but does NOT supply the local write rule, so it is an architecture lever, not a plasticity rule.  <https://arxiv.org/html/2601.00984v2>
- (NEW) Latent Predictive Learning (LPL) and CLAPP-style local self-supervised rules (arXiv:2010.08262 CLAPP; LPL biorxiv 2022.03.17.484712). NEW. Search + abstract: a local plasticity rule with a predictive component and a plasticity threshold yields disentangled representations WITHOUT labels OR negatives (LPL), and online contrastive-predictive SGD reduces to a GATED HEBBIAN rule (CLAPP). Supports rank-2 predictive/JEPA with a label-free, negative-free, LOCAL write gated by prediction-success. Could not open CLAPP PDF cleanly (binary); LPL at abstract depth only.  <https://arxiv.org/pdf/2010.08262>

## Concrete ideas

- **BTSP-style one-shot instructive WRITE of the role->filler binding into the toy substrate, then read key-only basin recovery. Present a role cue; trigger a single fixed-shape 'instructive plateau' potentiation pulse (not a metric trigger) that writes Delta_w = P(1-w)f_P(eligibility) - D w f_D(eligibility) over co-active role/filler eligibility traces (rule from PMC10484462). Carves a basin around the bound role+filler in ONE pass. Readout = native top_index_hits / basin-membership for role-target above chance, with a key-only (role-only) cue.** [local-dynamic; Pre-Phase-5-prime Stage-1 write-then-read toy (kickoff seed). Does NOT require lifting the Phase 5-prime fence.]
  - writes structure: Plateau-gated potentiation imprints a synaptic bump (attractor) tying the role's eligibility pattern to the filler region in one shot; the basin IS the written role-discriminative structure. Unlike the phase4 centroid-mean (push-down-only, flat zero-margin per EBM-2006/lecun-06), the asymmetric P*(1-w) potentiation vs D*w depression creates a non-flat margin without a contrastive negative.
  - test: Toy FHRR substrate ~4 roles, small codebook. One-shot BTSP write per (role,filler); read key-only basin-membership (NOT top-1, per reports/066). Controls: random-codebook fails; shuffled role-filler eligibility fails to form a recoverable basin; lower-D arm separates write from capacity wall (reports 058/065). Falsifier: if key-only still gives no basin (065/066 signature persists), BTSP does not rescue the binding ALGEBRA and the defect is upstream of any objective.

- **Temporal-Contrastive / single-pass dual-propagation WRITE: implement the rank-1 contrastive objective WITHOUT an explicit negative-construction step. Maintain two oppositely-nudged settles on a role cue -- free (role only) and clamped (role+true filler) -- and update by the local difference, via dual-propagation compartments s+ - s- (Hoier 2024, arXiv:2402.08573) in one relaxation, or via integral-feedback per-DOF under an alternating clamp protocol (Falk 2025, arXiv:2312.17723).** [local-dynamic; Pre-Phase-5-prime Stage-1; informs whether to lift the Phase 5-prime deltaE fence later.]
  - writes structure: The local (clamped - free) coactivation difference IS the pull-up term EBM-2006 prescribes against the push-down-only flat surface; it writes a margin separating the true filler basin from role-shuffled fillers. The single-pass / integral-feedback form removes the explicit predicted-id negative the FAILED phase3b error_driven_learner used (Fail Rate 1.0), addressing the documented prior-failure risk.
  - test: Same toy. Compare (a) dual-prop single-pass contrastive write vs (b) old two-phase error_driven_learner, multi-seed, basin-membership readout. Controls: no-clamp ablation fails; role-shuffled-clamp (wrong filler) must NOT write a recoverable role-target basin; shuffled-role gauge deltaE ~ 0; lower-D arm. Headline: key-only role-target basin-membership above chance with CI.

- **Recall-gated SELF-SELECTION of negatives/positives during consolidation replay. Replace 'sample role-shuffled negatives uniformly' with Lindsey & Litwin-Kumar's recall-gate: consolidate a replayed (role,filler) binding into the slow store only when its current recall overlap r = (stored_basin . replayed_cue) clears a FIXED threshold theta; reliable repeated bindings self-amplify, spurious one-shot crosstalk is filtered.** [thermostat-risk; Phase 4 consolidation objective (the centroid-mean write); test as a Stage-1 toy variant first.]
  - writes structure: Gating the slow write on recall overlap raises the SNR of consolidated role-target basins relative to crosstalk, so the WRITTEN structure is dominated by reliably-recallable role->filler associations rather than the flat mean of all members. The margin emerges from the gate's filtering statistics, not from an arbitration.
  - test: Toy with repeated vs one-shot bindings. Fixed-theta gate on recall overlap; multi-seed. ANTI-HOMUNCULUS GUARD: g must be a FIXED function of a LOCAL overlap computed by the same settling dynamics (measurement of a local dynamic), NOT an if-metric-then-route branch -- if theta is tuned per-condition or selects among candidate writes, it FAILS the filter and must be reshaped as a continuous plasticity gain. Control: ungated consolidation shows lower role-target SNR; randomized gate (theta on noise) must not help.

- **Dense-AM / lower-D control as the capacity-wall adjudicator, using the threshold-nonlinearity distributed code (Krotov-Latham 2026, arXiv:2601.00984) as the substrate for the Stage-1 write arms. Run every Stage-1 write (BTSP, contrastive, predictive) in BOTH the current FHRR-dim regime AND a dense-AM / lower-D regime with threshold nonlinearity Theta(h-theta).** [offline-statistic; Stage-1 toy control arm; gates the rebuild-vs-surgical decision in rebuild_signal.]
  - writes structure: Does not itself write role structure -- it is the CONTROL separating 'objective is wrong' from 'basins are crosstalk-floored at 1/sqrt(D)' (reports 058/065). Steeper threshold-nonlinearity basins reduce crosstalk so a correct write can show above-chance key-only recovery a 1/sqrt(D) floor was hiding.
  - test: For each write rule, report key-only basin-membership at current D and at lower-D/dense-AM. If null persists across BOTH the contrastive AND predictive families AND the lower-D arm, that is the documented force-rebuild-from-Phase-1 condition (rebuild_signal). If lower-D rescues it, the defect was capacity, not objective. NOTE: the 2026 paper's own rule is NOT local (global reconstruction argmin) -- use only its ARCHITECTURE (threshold nonlinearity, distributed code); supply the local write from BTSP/contrastive/LPL.

- **LPL/CLAPP local predictive WRITE for the rank-2 family: a label-free, negative-free gated-Hebbian rule whose gate is prediction success. Settle from a partial role cue, predict the filler region via native unbind-then-rebind self-target, and apply a Hebbian update gated by a fixed plasticity threshold on prediction-consistency (LPL, arXiv:2010.08262 / biorxiv 2022.03.17.484712).** [local-dynamic; Pre-Phase-5-prime Stage-1, rank-2 predictive arm.]
  - writes structure: The predictive consistency between successive settles supplies the self-supervised target the unsupervised centroid-mean pass lacks (PAM's 'missing association BETWEEN patterns'); the local rule writes a role->filler predictive basin without constructing explicit negatives (avoiding the phase3b negative-construction failure mode) and without labels.
  - test: Toy: predictive local write vs centroid-mean; multi-seed; key-only basin-membership. Controls: shuffled role-filler pairing destroys recoverability; held-out roles (AAR no-inductive-transfer caution); lower-D arm. PORT RISK to flag: every PC/JEPA primary writes into an external Euclidean predictor -- the FHRR-native unbind-then-rebind self-target is the core unproven step. Card arXiv:2509.01987 and 2402.10814 (link_only) from primaries before leaning on them.
