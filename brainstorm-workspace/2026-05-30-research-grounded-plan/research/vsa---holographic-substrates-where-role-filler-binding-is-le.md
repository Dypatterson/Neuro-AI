# Research angle: VSA / holographic substrates where role/filler binding is LEARNED and WRITTEN — does GSBC or a block-code substrate help WRITE vs READ? Verdict: GSBC, Soft-TPR, and ArSyD converge on a single load-bearing answer that CORROBORATES the project diagnosis. All three keep role/codebook vectors FIXED-RANDOM (matching Soft-TPR's prior result that fixed-random roles are FINE) and write role-discriminative structure NOT by training the binding algebra or the codebook, but by a SWAP-reconstruction objective: exchange one filler between two examples that share a role, require the decoder to reconstruct the swapped pair, and modularity falls out 'by construction' with no explicit regularizer and no supervisor. GSBC out-of-the-box is a READ-side win only (fixed-random codebooks + a pure iterative resonator/factorizer readout; only a CNN front-end trains), so it is correctly PARKED behind first showing structure CAN be written. The swap objective is the cheapest WRITE candidate and is structurally distinct from the failed phase3b error-driven push/pull (which mined the negative from the learner's own predicted-id; the swap negative is implicit and never self-mined).

## Key findings
- (IN-CORPUS) GSBC ('Factorizers for Distributed Sparse Block Codes', corpus 2303.13957) uses ENTIRELY FIXED-RANDOM codebooks ('F-factor codebooks, each with n-th-root-of-C fixed codevectors'); the Block Code Factorizer is a PURE iterative inference / resonator-style READOUT (threshold nonlinearity + conditional random sampling + l-inf similarity s_inf = 1 - l_inf(x_i - x_j)); only a CNN front-end and an optional projection W' are trained. GSBC's headline win is READ-side capacity for factorizing a product of codebooks (~5e6 operational, ~5000x over binary-SBC+dot-product), NOT a write/learning step. Opened primary (arxiv html v2).  <https://arxiv.org/html/2303.13957v2>
- (IN-CORPUS) Soft Tensor Product Representations (corpus 2412.04671) keeps ROLE VECTORS FIXED-RANDOM ('randomly-initialised dense role embedding matrix M_xi_R ... does not backpropagate gradients to this matrix', Appendix B.4.1). Structure is WRITTEN by: Soft-TPR form penalty ||z - psi*tpr||^2 + reconstruction + VQ-VAE filler quantization, plus a weakly-supervised FILLER-SWAP term (lambda1 over swapped-pair reconstruction + lambda2 CE). Independently corroborates the project's Soft-TPR-derived claim that fixed-random roles are fine and the bug is the OBJECTIVE. Opened primary (arxiv html v2).  <https://arxiv.org/html/2412.04671v2>
- (NEW) ArSyD (Architecture for Symbolic Disentanglement, NEW 2412.19847, Dec 2024) is the cleanest VSA-native WRITE result: generative-factor and value hypervectors are SAMPLED-AND-FROZEN at init; object = superposition of value HVs selected by softmax attention over the FROZEN codebook (a = softmax(V'K/sqrt(D)); V* = sum_k a_k V_k). The ONLY loss is reconstruction MSE (Eq 5/6) — NO contrastive/negative/disentanglement penalty. Disentanglement is 'by construction' via a weakly-supervised FEATURE-EXCHANGE: take a pair differing in one factor, SWAP that one feature vector, require both swapped reconstructions to match. The swap operation, not a regularizer, forces each component to carry one factor. Opened primary (arxiv html v1).  <https://arxiv.org/html/2412.19847v1>
- (NEW) The swap-reconstruction WRITE mechanism has a deep lineage: Dual Swap Disentangling (NEW 1805.10583, 2018) introduced encode-swap-decode — swap shared-attribute dimensions of a labeled pair, decode to reconstruct, imposing dimension-wise modularity from only same/different pair labels (weak supervision), no per-dimension regularizer. ArSyD and Soft-TPR are the VSA/TPR-native descendants. SAME shape as the project's rank-1 'contrastive/margin with role-shuffled negatives' candidate, but with a CRITICAL difference: the swap negative is IMPLICIT and structural (a real other-example's filler), never mined from the model's own predicted-id. PDF was binary-garbled; read from search synthesis + corroborating ArSyD/SoftTPR primaries.  <https://arxiv.org/abs/1805.10583>
- (IN-CORPUS) HLB / Hadamard-derived Linear Binding (corpus 2410.22669) makes the binding op trainable: B(x,y) = x (elementwise) y, real-only, O(d), with a STABLE NORM (expected |component| = 1 so norm stays sqrt(d) at any binding depth) and clean gradient flow — explicitly contrasted with HRR/FHRR circular-convolution binding whose norm explodes/vanishes during backprop. Directly relevant if the project wants a DIFFERENTIABLE consolidation pass over a holographic substrate without FHRR's complex-FFT gradient pathology. Opened primary (arxiv html).  <https://arxiv.org/html/2410.22669>
- (NEW) Phasor Agents (NEW 2601.04362, Jan 2026) gives an anti-homunculus-clean, complex-phasor (z in C, FHRR-cousin) consolidation: a three-factor local plasticity rule dW_ij = eta g(t) M(t) u_ij e_ij with phase-coincidence h_ij = Re(z_i conj(z_j)) and dual-timescale eligibility traces, plus an OFFLINE 'sleep-staged' NREM consolidation dW_ij <- eta_capture g_spindle(t) PRP(t) e_ij_slow ('tag-now, capture-later'). The spindle gate is a fixed reference oscillation and PRP rises autonomously when M(t) crosses threshold — NO supervisor reads a network metric. A concrete template for an offline/batch consolidation dynamic on complex-phasor states. Opened primary (arxiv html v1).  <https://arxiv.org/html/2601.04362v1>
- (NEW) TPAM (Threshold Phasor Associative Memory, Frady & Sommer; NEW 1901.07718 / PNAS 2019) stores continuous-valued complex-PHASOR patterns as stable fixed-point attractors under a LYAPUNOV function (Hopfield-like), with a neural threshold that boosts capacity and SUPPRESSES flat/very-noisy postsynaptic phase distributions. Directly the energy-based READ side for FHRR-like complex states, and the threshold's suppression-of-flat-distributions is notable given the project's FLAT zero-margin failure signature. Read from search synthesis (PDF/HTML not opened); card before load-bearing use.  <https://arxiv.org/abs/1901.07718>
- (IN-CORPUS) The project's phase3b error-driven (push-down/pull-up, lr_pull=0.1 lr_push=0.05, seed 17) ran 151 consolidations and STAYED FLAT: Fail Rate ~1.0-1.4, Mean Q ~0.04-0.08, generalization masked_token error_driven=0.050 barely above random=0.036 and crushed by the bigram baseline=0.199 (reports/phase3b_multimask/03_phase3b_error_driven.md:31-241). Single-seed, masked-token Q (NOT hit_role), top-1, and its negative was the learner's OWN predicted_id — the self-mined-negative failure mode the swap objective avoids. Confirms the project's HIGH prior-failure-risk caveat on rank-1 is real and pinpoints WHY a swap negative is the surgical change.  <https://arxiv.org/html/2412.19847v1>

## Concrete ideas

- **SWAP-reconstruction consolidation (ArSyD/Soft-TPR/Dual-Swap shape) as the Stage-1 write objective, replacing the rank-1 'role-shuffled-negative contrastive' framing. Toy: ~4 roles over a small FIXED-RANDOM codebook. Build pairs of bound items that share a role but differ in one filler. Offline/batch consolidation: encode both, EXCHANGE the differing filler's contribution between the two superpositions, require the native FHRR unbind-then-rebind to reconstruct BOTH swapped items. The write target is the swapped reconstruction, never the model's own predicted_id.** [offline-statistic; Stage-1 pre-Phase-5-prime toy (per the consolidation/role-structure seed note staged plan; does NOT require lifting the Phase-5-prime fence).]
  - writes structure: Reconstruction pressure on swapped pairs forces each role-slot to carry exactly one filler independently: if a slot leaked into another role, the swap reconstruction would be wrong. Modularity is written 'by construction' (ArSyD Eq 5/6, no regularizer; Soft-TPR lambda1 swap term 2412.04671). The role basin emerges as the geometry that makes swapped reconstruction a local energy minimum.
  - test: Stage-1 write-then-read toy. Headline: native top_index_hits (basin-membership, NOT top-1 cosine — the reports/066 lesson) for the role-target above chance. Controls REQUIRED: (a) no-swap ablation (plain reconstruction) must NOT modularize; (b) random-codebook must fail; (c) shuffled role-atom pairing must destroy recoverability; (d) a lower-D arm to rule out the 1/sqrt-D capacity wall (reports 058/065).
