## Summary
The cluster strongly supports the project's own self-diagnosis and supplies the missing piece. EBM-2006 (opened, primary) names our exact failure: a push-down-only / store-as-is consolidation write can 'collapse to flat constant-zero energy' (p.10), so the role-target sits where a random atom sits (hit_role=0.000). The cure EBM-2006 prescribes is a contrastive write that also PULLS UP on the 'most offending incorrect' role-config (p.9, Eq.7 margin loss). Crucially, this repo ALREADY tried that (phase2/error_driven_learner.py, lr_pull/lr_push), and phase3b shows it stayed at Mean Q~0.05 / Fail Rate 1.0 -- so the open question is not whether to add a pull-up term but HOW to construct the role-competitor negative, and whether the substrate can hold the gap. The strongest fresh candidate is the FEP self-orthogonalizing rule (2505.22749, opened HTML): an explicit LOCAL Hebbian-minus-anti-Hebbian update (Eq.25, Sanger-like) that writes orthogonal attractors as an emergent fixed-point with no controller -- anti-homunculus-clean, but link_only/no-card, on a non-FHRR substrate, and not yet shown to separate role from content. SQHN (opened) is an existence proof that a purely-local no-backprop rule builds recoverable online-continual memory (via neuro-genesis), and EqProp (abstract only) is a candidate local gradient engine. For evaluation: MQAR (opened) is the right write-then-read template (discrete key->value recall, sweepable gap/load), already used as an external gate; the negative-results paper (opened) is too thin to certify nulls, so lean on the project's own multi-seed-CI + precommitted-control discipline. Headline recommendation: the fair test of 'did the objective write role structure' is the kickoff seed's Stage-1 toy write-then-read -- hit_role >> 0 (or Delta-E CI-disjoint from zero) on a NATIVE FHRR readout, with a random-codebook control AND a shuffled-role (gauge) control whose Delta must be ~0. All of this is upstream of the PAUSED Phase-5' headline; targeting that Delta-E headline directly requires the user to lift the fence."

## Supported claims

- **pdf:energy-based-learning-2006** (primary_opened=True): EBM-2006 (primary, opened) states that a write/learning objective that only PUSHES DOWN on the energy of the correct configuration, without PULLING UP on incorrect configurations, can produce 'a collapsed solution in which the energy is constant and equal to zero' (p.10). It works only with architectures where pushing down on the correct answer automatically raises others. This is the textbook diagnosis of our exact failure mode: a co-occurrence / store-as-is consolidation write lays down no contrast, so the role-target energy sits flat where a random atom sits.
  - _caution:_ EBM-2006 is a generic framework, not an FHRR/MHN result; collapse is a sufficient-condition warning, not a proof our specific objective collapses. The project must still run the write-then-read control.

- **pdf:energy-based-learning-2006** (primary_opened=True): EBM-2006 (opened, p.9) gives the canonical learning shape needed to write recoverable structure: define the 'most offending incorrect answer' Y-bar (lowest-energy wrong config) and design a loss that pushes down E(correct) while pulling up E(Y-bar). The generalized-perceptron loss (Eq.7) pulls up only on the model's argmin and 'has no mechanism creating an energy gap/margin' between correct and incorrect, so margin-based losses are preferred. This is the precise specification of what a role-discriminative consolidation objective must do.
  - _caution:_ Requires defining the 'incorrect role config' for an unsupervised FHRR consolidation pass; the project has no labelled role targets at runtime, so the contrast must be constructed offline/batch (consistent with the 'error-driven only in batch offline passes' STATUS policy).

- **pdf:energy-based-learning-2006** (primary_opened=True): EBM-2006 (opened, Eqs.45-47) frames latent-variable EBMs: marginalize over the latent Z, infer Y via the free energy F(Z) = -(1/beta) log integral exp(-beta E(z,Y,X)). Role-binding maps onto this: the role is a latent/clamped coordinate. This gives a principled, normalization-free way to make role a first-class energy coordinate, which the Phase-5 design (lines 256-303, opened) already gestures at with its content-prior vs role-prior branch energies.
  - _caution:_ Algebraic/free-energy formulation is not evidence of a Hopfield basin; per the project's standing caution, decode/energy success != basin retrieval. A native FHRR readout control is mandatory.

- **pdf:energy-based-learning-2006** (primary_opened=True): The project ALREADY built and ran the EBM-2006 push-down/pull-up write as phase2/error_driven_learner.py ('correct atoms pulled toward decoded-slot, wrong predictions pushed away'; lr_pull=0.1, lr_push=0.05). The phase3b error-driven report shows it ran 9 consolidation events on wikitext and the retrieval Mean Q stayed at 0.04-0.095 with Fail Rate = 1.0000 throughout. So a naive contrastive term bolted onto the existing FHRR-similarity-MHN write did NOT write recoverable structure. This is project evidence (not just literature) that the fix is not merely 'add a contrastive term'.
  - _caution:_ phase3b is single-seed (seed 17), pre-dates the Phase-5 hit_role headline, and measured masked-token recall Q, not the role-prior-vs-content-prior Delta-E headline. It is suggestive, not a multi-seed graduation-grade null; the contrastive objective may have failed for tuning/architecture reasons rather than being fundamentally inert. Re-run with controls before concluding.

- **pdf:energy-based-learning-2006** (primary_opened=True): Reports 062-066 (opened 062 head; 065/066 verdicts) establish the project's own routing: hit_role = 0.000 across D1/D3/E1/M1; Report 062 concludes 'the bottleneck is not retrieval mechanism; it is substrate training' and pre-commits the Tier-2 training-time (M2) branch. Report 065/066 used MQAR as an external architecture gate and found key-only MHN basin retrieval top_index_hits = 0/3072 even after a GHRR algebra swap. The project record independently converges on EBM-2006's diagnosis: the write, not the readout, is the gap.
  - _caution:_ These are smoke-scale (n=3 seeds x 30 cues) per 062's own preamble; STATUS confirms 'no path yet has an n>=10 result with a control.' The convergence is strong but not yet graduation-grade.

- **arxiv:2505.22749** (primary_opened=True): FEP self-orthogonalizing-dynamics (2505.22749, opened HTML) gives an explicit LOCAL learning rule (Eq.25: Delta J_ij ~ sigma_i*sigma_j - L(b_i + sum_k J_ik sigma_k)*sigma_j, Hebbian minus anti-Hebbian prediction) that the authors show is 'analogous to Sanger's rule for PCA' and yields 'approximately orthogonal attractor states.' Orthogonalization is an EMERGENT fixed-point property of minimizing accuracy + a KL-to-prior complexity term (Eq.14), not an imposed constraint and not a global controller: each node uses only local bias and neighbor inputs. This is a concrete, anti-homunculus-clean candidate for WRITING role-discriminative basins.
  - _caution:_ link_only in the manifest (no full card yet); I opened the HTML primary, so it can motivate design but per the project promotion rule a full source card must be written before it is load-bearing implementation evidence. Its substrate is a binary/Langevin-sigmoid spin network, NOT FHRR/MHN; the anti-Hebbian rule would need re-derivation for complex FHRR atoms. It also does NOT demonstrate explicit role/content (factor) disentanglement, only orthogonalized attractors.

- **arxiv:1602.05179** (primary_opened=True): Equilibrium Propagation (1602.05179, abstract opened; PDF/HTML full-text retrieval failed) is a two-phase contrastive-Hebbian gradient engine: a free-phase fixed point and a weakly-clamped (output-nudged) fixed point, with a local weight update equal to the difference of pre/post-synaptic state products across the two equilibria, computing the gradient of the cost without a separate backprop pathway. It requires symmetric weights and fixed-point (energy-minimizing) dynamics. This is a candidate offline gradient engine for a consolidation objective that stays local.
  - _caution:_ I only successfully opened the ABSTRACT (the html/pdf full-text fetches 404'd / returned binary); the exact rho(s_i)rho(s_j) update equation is from the abstract's description, not the body. link_only, no card. Symmetric-weight + real-valued fixed-point requirements do not obviously hold for an FHRR complex-phasor substrate; treat as framing, not a drop-in.

It isolates 'did the model write a recoverable key->value association' from generic language ability. This is the right template for a role->target write-then-read test, and the project already used it as an external gate (Report 065/066).
  - _caution:_ MQAR is an external sanity-check, not the design-spec headline (Phase-5 headline is Delta-E role-prior vs content-prior, phase-5-unified-design.md:256-303). Per project discipline it stays a sanity check unless explicitly promoted. It tests value recall, not role-vs-content basin geometry, so it under-specifies our headline.

- **arxiv:2406.03980** (primary_opened=True): Negative-results methodology (2406.03980, opened HTML) is THIN on the rigor we need: it calls for open well-tested code and in-depth analysis of why a negative result occurred, but explicitly defers statistical-power, sample-size, pre-registration, and 'method limited vs we failed to tune it' criteria to 'a healthy review process' (their words). - **arxiv:2503.23390, arxiv:2507.11393, pdf:sqhn-2024** (primary_opened=True): Continual-learning eval baselines: ParetoCL (2503.23390, opened) frames stability-plasticity as multi-objective/Pareto and warns that fixed replay balances are suboptimal; VAE+MHN-CLS (2507.11393, opened) pairs a VAE (pattern completion) with an MHN (pattern separation) and reports ~90% on Split-MNIST with reduced forgetting. ## Mechanisms for writing role structure

### Contrastive EBM consolidation objective (push-down correct role-config / pull-up most-offending incorrect role-config), batch-offline  [pdf:energy-based-learning-2006, arxiv:1602.05179]
- AH-shape: offline-statistic — Quantity that moves: per-atom/per-binding energies during a fixed batch pass. The 'decision' (which config is correct vs offending) is the FIXED contrastive loss gradient, computed offline over a precommitted dataset -- NOT a runtime metric-reader. Passes the filter ONLY if it stays a batch-offline pass (STATUS live policy: error-driven updates banned at runtime). Control: shuffled-role / gauge control must give E[Delta]=0, and a random-codebook control must not produce the gap.
- maturity: proven-in-paper
- how it writes: An offline consolidation pass shapes the energy landscape so a cue bound to its CORRECT role-filler sits at lower energy than the same cue bound to an incorrect role-filler (the 'most offending' competitor, EBM-2006 Eq.7 generalized perceptron / margin loss). The role basin is written as the energy gap created by simultaneously lowering E(correct binding) and raising E(competitor binding). Equilibrium Propagation supplies the local gradient: free-phase fixed point minus weakly-clamped fixed point gives the weight change with no backprop pathway.
- relevance: EBM-2006 p.10 names our failure exactly: a push-down-only (store-as-is / co-occurrence) write collapses to flat energy, so role-target sits where a random atom sits (hit_role=0.000). The pull-up term is the missing ingredient. BUT the project's phase3b error_driven_learner already implemented push+pull and stayed at Mean Q~0.05 / Fail Rate 1.0 -- so the naive form is not enough; the contrast construction (how the 'offending' role-competitor is defined) is the live design question.

### FEP self-orthogonalizing local Hebbian-minus-anti-Hebbian rule (Sanger-like)  [arxiv:2505.22749, pii:S037015732300203X]
- AH-shape: local-dynamic — Quantity that moves: synaptic couplings J under a purely local rule (each node sees only its bias + neighbors). The 'decision' to orthogonalize lives in the fixed anti-Hebbian subtraction, an emergent fixed-point of minimizing accuracy + KL-to-prior complexity -- no controller, no metric-gate. Clean pass. Control: ablate the anti-Hebbian term (pure Hebbian) and show orthogonalization / hit_role collapses; that isolates the rule as the cause vs hidden arbitration.
- maturity: plausible
- how it writes: Each consolidation update is Delta J_ij ~ sigma_i*sigma_j - prediction_i*sigma_j (Eq.25): the anti-Hebbian prediction term subtracts the component of a new pattern already explained by existing attractors, so only the orthogonal residual is written. Over a stream, attractors self-decorrelate (emergent, analogous to Sanger's rule). If role and content are presented as partially-overlapping patterns, the rule forces newly-written role basins to be orthogonal to existing content basins -- writing separation that a similarity readout can then resolve.
- relevance: Directly attacks 'structure never written': it actively writes orthogonal (separable) basins instead of bundling everything into overlapping superposition. Counter to the project's anti-overlap signature worry, it writes separation at consolidation time rather than relying on a sharper readout. Maturity capped at 'plausible' because the paper's substrate is a binary/Langevin spin net, NOT FHRR, and it does not demonstrate explicit role/content factor disentanglement -- only orthogonal attractors.

### SQHN-style local-MAP write with neuro-genesis (grow a neuron/atom for a poorly-explained role-binding)  [pdf:sqhn-2024]
- AH-shape: local-dynamic — Quantity that moves: reconstruction error / local code allocation. The growth 'decision' is a fixed local threshold on reconstruction quality (a measurement of a local dynamic), not a supervisor choosing winners. Borderline: must be framed as a fixed-threshold allocation dynamic, NOT an 'if novelty>x then act' runtime router. Control: random-allocation baseline (grow on a coin flip) must underperform the error-gated allocation.
- maturity: proven-in-paper
- how it writes: An online MAP rule allocates a new sparse code (neuro-genesis) when an incoming role-binding is poorly explained by existing atoms, and applies a local update otherwise. The role-discriminative target is written as a freshly-allocated basin whenever the current landscape cannot reconstruct the bound pattern -- so role configs that currently collide with random atoms get their own coordinate instead of being averaged into a shared bundle.
- relevance: If the failure is that distinct roles collapse onto shared atoms (no separation written), capacity-via-growth directly writes the missing coordinate. Existence proof that a local no-backprop rule builds recoverable online-continual associative memory. Caveat: SQHN is a discrete sparse-quantized substrate, not FHRR; 'use as benchmark, not drop-in proof' (card). The project already has add_pattern / neuro-genesis-adjacent machinery in phase4/consolidation.py to adapt.

### Latent-variable role coordinate via free-energy marginalization (role as clamped latent Z)  [pdf:energy-based-learning-2006, arxiv:2006.04120]
- AH-shape: offline-statistic — Quantity that moves: the joint energy coupling, shaped offline. The apparent 'decision' (role-prior vs content-prior) is just which latent is clamped -- both branches run the SAME energy minimization; the headline is a measurement of their energy difference, not an arbitration. This is the design-spec-sanctioned shape (phase-5-unified-design.md:256-303). Control: the spec's own content-prior branch is the within-experiment control.
- maturity: plausible
- how it writes: Treat the role as a latent variable Z and write the energy E(content, role, cue) so that inference marginalizes/min-es over Z (EBM-2006 Eqs.45-47, F(Z)=-1/beta log sum exp(-beta E)). Consolidation shapes E so that the role-prior branch (Z clamped to the cue's role-fillers) reaches a lower free-energy fixed point than the content-prior branch -- which is exactly the Phase-5 Delta-E headline. The structure written is the energy coupling that makes role a low-energy explanatory coordinate.
- relevance: This is the project's own intended formulation; the gap is that NOTHING in the current write makes role a low-energy coordinate (Delta-E ~ 0, negative in spikes). The latent-variable EBM gives the objective whose gradient would write that coupling -- but Phase 5' is PAUSED, so authorizing this requires the user to lift the fence.
