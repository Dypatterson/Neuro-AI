## Summary
The cluster adjudicates cleanly to WRITE, not read. The project record (Reports 058/062/063/064, all opened) shows the Phase 5 failure is ABSENCE: hit_role=0.000 across four retrieval families, best-case rank_role 263.7/1064 with random-prior beating role-prior in ~1/3-1/2 of cues, and sharpening interventions making rank WORSE - the role-target sits where a random atom sits. The VSA/HRR literature the project routes to for legibility (resonator 2208.12880, pseudo-inverse PMC9759586, opened) is uniformly a READ over FIXED codebooks whose recovery degrades under bundling crosstalk (alpha~0.1-0.2) - it can only surface structure consolidation already wrote, which validates parking GSBC. The genuine WRITE mechanisms in the corpus are: (1) the project's own offline CONTRASTIVE consolidation (EqProp free/nudged + role-shuffled negatives), whose theory (Hopfield-Fenchel-Young margin: Hebbian-only writes zero role/role-shuffle margin) is the cleanest mechanistic root-cause for why structure was never written, anti-homunculus-clean as a local dynamic, but NEVER RUN; (2) TEM (PMC7707106, opened) - a pure predictive objective that provably writes a learned structure/content factorization, but via BPTT + an anatomical scaffold; (3) Dorrell-Whittington range-modularity (2410.06232) - writes factorization from rectangular-support data, but ALREADY tried as range-shaped replay (Report 111) and got 'novelty without retrieval' on this substrate. Decisive cross-cutting finding from Soft TPR (2412.04671, opened): roles fixed-random is FINE (Soft TPR recovers structure with fixed random roles) - so the project's fixed FHRR roles are NOT the bug; the bug is the OBJECTIVE, and Soft TPR's recoverability comes precisely from a swap/contrastive supervised margin the project's Hebbian co-occurrence consolidation lacks. Bottleneck = WRITE (objective), not READ (algebra/legibility). The unblocked move is the kickoff seed's Stage-1 write-then-read toy with a contrastive offline consolidation term, run on this branch (NOT Phase 5-prime, which stays fenced).

## Mechanisms for writing role structure

### Contrastive offline consolidation (EqProp free/nudged + role-shuffled negatives) - the project's M2 / Tier-2 path  [arxiv:2411.08590, arxiv:2412.04671]
- AH-shape: local-dynamic — What moves locally: per-atom FHRR phasor under a contrastive-Hebbian rule (CHL/EqProp - gradient of energy at equilibrium, local in space). The apparent 'decision' lives in the nudged-phase settling toward the target (a fixed geometric force) and the fixed contrastive sign (add on positives, subtract on role-shuffled negatives). No metric is read at runtime to gate or route. Negative construction is uniform role-shuffle = data augmentation, NOT a metric-triggered choice. Control: role-shuffled-negatives must beat a no-negatives ablation, and a same-margin random-atom control must NOT recover, to show it is margin-writing not memorization. CLEAN, conditional on the offline-only fence holding.
- maturity: speculative
- how it writes: Runs in the OFFLINE consolidation phase (Hebbian runtime untouched, per the project's BAN on online error-driven updates). Two-phase local dynamic: a free phase settles the substrate on a role-cue, a nudged phase settles the same energy with a small local geometric pull lam*(true_filler - s) toward the target; the per-atom contrastive-Hebbian update (a_nudge*s_nudge - a_free*s_free)/lam carves an energy basin at the true filler for cues of the form r(x). Negatives are role-shuffled bindings (same fillers, WRONG roles) sampled uniformly - data augmentation, not a metric choice. This installs the loss MARGIN between role-aligned and role-shuffled basins that Hebbian-only consolidation lacks (Hopfield-Fenchel-Young: margin determines exact retrieval), which is exactly what is needed to move hit_role off 0.000.
- relevance: Directly targets our failure: the substrate has NO role-target basin (random-prior beats role-prior, Report 058), and the brief's theory says this is because Hebbian-only consolidation writes zero margin. EqProp+negatives is the only candidate that writes a basin via a margin. NEVER RUN - it is a brainstorm proposal, the explicit unblocked next move per Reports 062:91/063:109/064:102 (M2), and the natural Stage-1 'write-then-read' test in the kickoff seed.

### Range-shaped data/replay (Dorrell-Whittington rectangular-support modularity)  [arxiv:2410.06232]
- AH-shape: offline-statistic — The range/rectangularity is an OFFLINE batch property of the replay buffer, set before consolidation - exempt from the thermostat rule (no runtime metric read). What moves locally is the same consolidation update; only the input distribution changes. CLEAN in shape. The control is the project's existing rectangularity diagnostic.
- maturity: proven-in-paper
- how it writes: Does NOT change the objective - shapes the DATA: if the replay buffer's role x content support is made rectangular (each role co-occurs with the full range of fillers and vice versa), a reconstruction/efficiency objective is provably forced to modularize role and content into separate subspaces. Structure is written by data geometry interacting with the existing consolidation objective.
- relevance: PARTIALLY FALSIFIED on our substrate: Report 111 (n=10) ran range-shaped replay (range_postsettle) and got 'novelty without retrieval' - rectangularity changed (0.99->0.16) and provenance geometry moved, but held-out top1/topk retrieval did NOT follow; the presettle positive control preserved novelty (d_eff +19 to +27) but still produced no useful retrieval. The Dorrell-Whittington theorem is for nonnegative LINEAR autoencoders; FHRR+MHN is not that regime. Re-read Report 111 before re-proposing (kickoff seed flags this explicitly).

### TEM-style predictive factorization with two-timescale (slow structure / fast Hebbian) consolidation  [pmc:PMC7707106]
- AH-shape: local-dynamic — The fast Hebbian binding (M between co-active p neurons) is a clean local co-activity rule; the prediction objective is unsupervised (no labels, no controller, wake-sleep/Helmholtz-style). BUT the slow structure-learning is BPTT (global gradient over sequences) - an offline-statistic at best, and the MEC/LEC anatomical split is a hand-imposed scaffold (like MESH). Mixed shape: local on the memory side, offline-global on the structure side. Needs translation to a single local energy dynamic before it passes cleanly.
- maturity: plausible
- how it writes: A next-observation PREDICTION objective drives the system to discover an abstract structural code g (grid-like, generalizing) separate from a conjunctive content code p (place-like, environment-specific); binding is the g(x) outer-product conjunction stored in fast Hebbian weights M, while slow weights learn the generalizable structure. The factorization emerges from prediction-error minimization + an anatomical input split - structure is WRITTEN by the objective, not read from fixed codebooks.
- relevance: Strongest existence proof in the corpus that a PURE PREDICTIVE objective writes recoverable role/structure factorization with grid-like generalization. Tells us the project's consolidation objective (co-occurrence / atoms-as-is, Path C) is the wrong objective - prediction-of-next + a structural prior is what writes the split. Maps to the project's contextual-completion target. But TEM needs a structural scaffold (anatomy) to bootstrap - cautions against expecting a scaffold-free FHRR write.

### Soft-TPR weak-supervision (factor-swap reconstruction + match-pairing) on learned fillers over FIXED roles  [arxiv:2412.04671]
- AH-shape: fails — Two problems. (1) It is a GLOBAL end-to-end gradient-descent autoencoder loss - no local dynamic, would need a CHL/EqProp re-expression to fit the substrate (the same re-expression the M2 path provides). (2) The decisive disentanglement signal is WEAK SUPERVISION (factor-swap PAIRS), a labeled relational signal the project's corpus does not provide and which smuggles in an external 'which factor changed' teacher. The unsupervised-only term is just reconstruction + form-penalty. As stated it FAILS the local-dynamic filter and depends on supervision the project lacks.
- maturity: proven-in-paper
- how it writes: Keeps role vectors FIXED (random, not trained - same as the project) and writes recoverable filler structure via a global autoencoder: reconstruction + a Soft-TPR-form penalty ||z - psi_tpr||^2 that pushes the encoder output toward an explicit quantized TPR, PLUS weak supervision (swap-reconstruction loss on paired images where one factor differs, and a match-pairing cross-entropy forcing the swapped-role distance to exceed unchanged-role distances). Native unbinding (inner product with fixed role's unbinding vector) then recovers fillers without the decoder.
- relevance: Key NEGATIVE lesson: roles fixed-random is FINE (Soft TPR proves recoverable structure with fixed random roles) - so the project's fixed FHRR roles are NOT the bug. The bug is the OBJECTIVE: Soft TPR's recoverability comes from a swap/contrastive supervised signal that installs a margin between role-correct and role-swapped configurations - precisely the margin the project's Hebbian-only consolidation lacks. Converges with the M2 contrastive-negatives prescription.

### Fixed-codebook resonator / pseudo-inverse cleanup (read-side legibility, e.g. GSBC)  [arxiv:2208.12880, pmc:PMC9759586, arxiv:2410.22669]
- AH-shape: local-dynamic — The resonator settling is a clean local fixed-point dynamic (per-module unbind + auto-associative cleanup + saturation, from random seeds, no controller) - anti-homunculus clean AS A READOUT. But it is a readout, not a writer, so it is out of scope for the write question.
- maturity: proven-in-paper
- how it writes: Does NOT write structure - it is a READ/decode mechanism. Given an already-bound product over FIXED codebooks, it iteratively unbinds each factor against the current estimates of the others and cleans up against the codebook (resonator), or applies a one-shot pseudo-inverse + dictionary cleanup. A cleaner read can only surface structure that consolidation already wrote.
- relevance: DOES NOT address our failure. The kickoff seed PARKED GSBC for exactly this reason: our failure is absence (rank_role ~ random, random-prior wins), so a cleaner readout has nothing to surface. Recovery in these methods also degrades under bundling crosstalk (PMC9759586: alpha~0.1-0.2), confirming 'exchange-rate not impossibility' - relevant only AFTER a write objective lays down structure and the bottleneck becomes legibility.
