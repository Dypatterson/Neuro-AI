## Summary
Cluster grounded against primaries (PAM, PAM2, LLM-JEPA, LV-EBM opened from local PDFs; tPC/PC-neocortex/AAR/Recchia/feature-space-AM read via WebFetch on abstracts). The cluster's defining move is real and directly on-target: PAM's L_assoc (JEPA contrastive loss over temporal co-occurrence with stop-grad/EMA targets) WRITES a learned source->target-region map from experience, beyond similarity, with no supervisor or hand-built graph - and PAM explicitly diagnoses the exact gap the project is stuck on (modern Hopfield/MHN store isolated patterns with 'no structure BETWEEN them'; our consolidation never writes the role->target between-pattern association, so the role-target sits where a random atom sits). PAM2 strengthens this into a consolidation story: contrastive replay UNDER a capacity bottleneck (compression-forces-abstraction, explicitly analogized to hippocampal replay) writes structure that transfers, where single-pass association does not. tPC (2305.11982) is the most substrate-relevant: a predictive-coding next-item objective reduces to an asymmetric-Hopfield write + whitening - a concrete way to lay a directed role->target coupling into the substrate. LV-EBM supplies two anti-homunculus-clean recipes (contrastive with role-shuffled negatives, or collapse-preventing regularization) for an OFFLINE consolidation energy term - which is exactly the project's still-open M2 path (training-time EqProp + role-shuffled negatives, the only Phase-5 family not exhausted at smoke scale per Reports 062-064, re-verified at cited lines). Three hard cautions: (1) every cluster source writes into an external predictor/encoder, NOT into an FHRR basin recovered by a native readout - the port is unproven and is the kickoff seed's Stage-1 go/no-go; (2) AAR shows these objectives write CORPUS-SPECIFIC associations that fail inductive transfer (test held-out roles); (3) arxiv:2402.10814 is mislabeled - it is feature-space (similarity) autoassociation, not predictive coding, and as such is a foil, not a write mechanism (same legibility-not-write class as the correctly-parked GSBC). Phase 5-prime is PAUSED; this is grounding the objective space only - lifting the fence to run an M2-style consolidation-objective experiment is the user's call. 'Literature supports' a predictive/contrastive consolidation objective writing role->target structure; 'this project has shown' only that its current similarity-based consolidation does NOT (hit_role=0.000, anti-overlap signature, smoke scale)."

## Supported claims

- **pdf:pam-2026** (primary_opened=True): PAM's write mechanism is a JEPA/contrastive predictor loss over temporal co-occurrence, NOT a similarity store: L_assoc = sum_{t+ in N_tau(t)} d(z_hat(t), s_bar(t+)) - lambda * sum_{t- not in N_tau} d(z_hat(t), s_bar(t-)), with stop-gradient/EMA targets s_bar to prevent collapse. The predictor g_phi maps a source state to the centroid of its temporal-neighbourhood region; retrieval is a forward pass + NN lookup in the predicted region. This is exactly an 'association beyond similarity' objective: it WRITES a learned source->target-region map into predictor weights from the structure of experience, with no task supervision and no hand-built graph.
  - _caution:_ PAM lives in a continuous Euclidean embedding space with an external predictor MLP + memory bank; it is NOT an FHRR/Hopfield write rule. Eq.4 is a global mini-batch gradient objective (offline/batch-statistic shape), not a local per-synapse settling dynamic. The card itself flags PAM as 'a conceptual direction, not evidence current wiring works.' Results are on a synthetic benchmark only.

- **pdf:pam-2026** (primary_opened=True): PAM explicitly positions modern Hopfield/MHN as encoding 'no structure BETWEEN stored patterns' - each memory is an isolated attractor; the predictor supplies the between-memory associative path while Hopfield-style completion supplies within-basin recall. This is the precise gap that maps onto our failure: our FHRR+MHN substrate stores atoms as isolated patterns and the consolidation step never writes a role->target BETWEEN-pattern association, so the role-target sits where a random atom sits.
  - _caution:_ PAM frames the between-memory structure as a separate learned predictor module, not as a basin in the same energy landscape. Porting it to FHRR would require the association to be written into the SAME substrate the native readout queries, which PAM does not demonstrate.

- **pdf:pam2-2026** (primary_opened=True): PAM2 reframes multi-epoch contrastive training under a CAPACITY BOTTLENECK (42.75% train accuracy on 373M co-occurrence pairs) as a consolidation mechanism explicitly analogous to hippocampal replay compressing episodes - and shows it extracts transition-structure concepts that transfer to unseen texts, where single-epoch PAM/AAR association does NOT transfer. This is the clearest literature instance of a consolidation-shaped objective (compression-forces-abstraction) writing structure that a downstream readout recovers.
  - _caution:_ PAM2 writes structure into a 29.4M-param contrastive encoder's weights, validated by clustering quality and unseen-novel assignment selectivity - NOT by a native FHRR basin readout. The 'consolidation' analogy is asserted, not mechanistically a replay dynamic over an energy landscape. Corpus-scale; do not overclaim for local toy experiments (card caution).

- **arxiv:2604.20850** (primary_opened=True): AAR (Dury 2026) trains a 4.2M-param contrastive predictor on passage co-occurrence and gets +8.6 Recall@5 on HotpotQA multi-hop retrieval (+28.5 on hard questions) - but inductive transfer FAILS: a model trained on train-split associations shows no improvement on unseen validation associations. The objective captures corpus-specific co-occurrences, not transferable patterns. This is a direct caution for our case: a contrastive/co-occurrence consolidation term may write role-target associations that are real but corpus/instance-specific, which is fine for episodic recall but will not generalize to held-out roles.
  - _caution:_ Link-only source; fetched abstract + key results via WebFetch, no full card written. Title resolved as 'Association Is Not Similarity: Learning Corpus-Specific Associations for Multi-Hop Retrieval' (manifest title 'Dury AAR'). Result is in text-embedding retrieval, not FHRR.

- **arxiv:2305.11982** (primary_opened=True): Temporal Predictive Coding (arxiv:2305.11982) is provably equivalent to a classical ASYMMETRIC Hopfield Network plus an implicit statistical-whitening step, and this whitening is what yields stable sequential (heteroassociative next-item) recall on structured inputs. This is the load-bearing bridge to our substrate: a predictive-coding next-item objective IS a Hopfield write rule with a whitening preconditioner - i.e. a learning objective that writes a cue->next-target association into a (potentially FHRR-compatible) Hopfield weight matrix via local prediction-error updates.
  - _caution:_ Link-only source; only the abstract was machine-readable (arxiv HTML 404; WebFetch read the abstract page). The AHN-equivalence and whitening claims are from the abstract - the per-layer error term and locality of the update were NOT confirmed from the full text. Asymmetric Hopfield is not the symmetric MHN this project uses; the energy/settling story differs.

- **arxiv:2402.10814** (primary_opened=True): arxiv:2402.10814 does NOT support a predictive-coding WRITE rule. Its true title is 'Associative Memories in the Feature Space' (Salvatori, Millidge, Song, Bogacz, Lukasiewicz): it computes similarity in a contrastively-pretrained EMBEDDING space instead of pixel space and stores low-dim semantic embeddings. It is still similarity retrieval, just in a better space - it relaxes storage cost, not the similarity assumption.
  - _caution:_ CONTRADICTS the manifest/card label 'Associative Memories via Predictive Coding' and tag 'predictive-coding'. The actual paper is feature-space autoassociation, not predictive coding. Surfacing as a corpus-metadata error, not paper-anyway. This source does NOT write role->target structure; it improves the readout space - which the kickoff seed already argues is moot when structure was never written.

- **arxiv:2509.01987** (primary_opened=True): arxiv:2509.01987 ('Semantic and episodic memories in a predictive coding model of the neocortex', Fontaine & Alexandre) shows a predictive-coding model recalls individual-example specifics only when trained on a SMALL number of items - episodic recall arises as a byproduct of OVERFITTING within a semantic-learning objective, not from a dedicated episodic write rule. Directly relevant: a generic predictive-coding consolidation objective tends to wash out instance-specific (role-discriminative) detail as it generalizes; you get episodic specifics only in the under-generalized regime.
  - _caution:_ Link-only; abstract fetched via WebFetch, no full card. The loss form and locality were not confirmed from full text. The 'episodic-from-overfitting' point is a structural caution, not a recipe.

- **pdf:lv-ebm-ami-2023, pdf:ami-2022** (primary_opened=True): LV-EBM/AMI (Dawid & LeCun 2023) frames JEPA training as energy-based: the joint-embedding predictor is trained either by CONTRASTIVE methods (push down energy on observed pairs, push up on negatives) or by ARCHITECTURAL/regularized methods (information-maximization / collapse-prevention without explicit negatives). Both are valid ways to shape an energy surface so that compatible (source,target) pairs sit in low-energy basins. This gives the project two anti-homunculus-clean recipes for an offline consolidation energy term that writes a role->target basin: contrastive (role-shuffled negatives) OR variance/covariance regularization to prevent collapse.
  - _caution:_ AMI itself (pdf:ami-2022) is flagged a NEGATIVE EXAMPLE in the matrix/card: its Configurator/controller pattern is exactly the homunculus this project bans. Use the energy-shaping math, not the agent architecture. The EBM framing is theory background, not a phase metric (card caution). pdf:ami-2022 read via card only.

- **pdf:llm-jepa-2025** (primary_opened=True): LLM-JEPA (Huang, LeCun, Balestriero 2025) shows an embedding-space JEPA objective added to standard LLM training outperforms input-space reconstruction across Llama3/Gemma2/OpenELM/Olmo and is robust to overfitting, by treating two VIEWS of the same knowledge (e.g. text and code) as mutual prediction targets in latent space. Relevance to us is the 'two views of one thing' framing: a role and its filler/target can be treated as two views, and a JEPA term trains a predictor to map one to the other in latent space.
  - _caution:_ This is an LLM training-objective result; the project's binding rule keeps the LLM as voice/interface, not the cognitive core (matrix caution, principles.md:18-21). It does not touch FHRR/Hopfield. It is a sanity check for 'embedding-prediction beats reconstruction', not evidence about FHRR role basins.

- **pmc:PMC4405220** (primary_opened=True): Recchia et al. ## Mechanisms for writing role structure

### Contrastive/JEPA consolidation term (role-shuffled negatives) over the FHRR substrate (the M2 path)  [pdf:pam-2026, pdf:lv-ebm-ami-2023, arxiv:2604.20850]
- AH-shape: offline-statistic — Anti-homunculus-clean IF kept as a fixed batch-offline energy term (the project already BANS online error-driven codebook updates at runtime; error-driven allowed in batch passes - STATUS live policy). What moves locally: per-atom embedding under energy descent. Where the apparent decision lives: the energy minimum / basin, not an 'if role then write' rule. The negative set (role-shuffled) is a precommitted control, not a runtime metric read. FAILS if the negatives are selected adaptively at runtime by reading a metric - that would be a thermostat.
- maturity: plausible
- how it writes: In an OFFLINE batch consolidation pass, minimize an energy that lowers d(predicted_target, true_role_target) and raises d(predicted_target, role-shuffled-negative) - PAM's Eq.4 L_assoc transplanted onto FHRR atoms. The consolidation step stops copying atoms as-is and instead does gradient/Hebbian-with-negatives updates that pull the role-target atom into a low-energy basin reachable from the role cue and push competitor atoms out. The 'write' is the batch energy-descent that reshapes codebook/landscape geometry so a role cue settles onto its target rather than a random atom. LV-EBM gives the collapse-prevention recipe (stop-grad/EMA or variance regularization) so the term doesn't trivially collapse all atoms together.
- relevance: Directly targets the diagnosed root cause: current consolidation writes atoms as-is/co-occurrence and never lays down a role->target association, so the role-target sits where a random atom sits (kickoff seed 60-68; Reports 062-064). A contrastive term is the candidate that raises role-target similarity and lowers competitor similarity. AAR is the caution: such associations may be corpus/instance-specific (no inductive transfer) - acceptable for episodic role recall, not for generalizing to unseen roles.

### Predictive-coding next-item write = Asymmetric Hopfield + whitening (temporal/role heteroassociation)  [arxiv:2305.11982]
- AH-shape: local-dynamic — Predictive-coding updates are local per-neuron prediction errors (the canonical anti-homunculus-clean dynamic) - settling minimizes prediction error, no supervisor. What moves locally: prediction-error neurons and synaptic weights. Apparent decision lives in error-minimization settling. CAUTION: confirmed only from the abstract; the locality of the update and the per-layer error term were not verified from full text (arxiv HTML 404).
- maturity: plausible
- how it writes: A predictive-coding objective that predicts the next item in a (role, target) sequence reduces - per the paper's abstract - to an ASYMMETRIC Hopfield weight update with an implicit whitening preconditioner. The cue (role/position) -> target association is written into the recurrent weight matrix by local prediction-error-driven updates; whitening decorrelates structured inputs so the heteroassociative recall is stable. Mapped to us: consolidation would write a directed role->target weight (an asymmetric coupling) rather than relying on symmetric MHN basins that store atoms in isolation.
- relevance: Our substrate is a SYMMETRIC MHN that stores isolated patterns (PAM's exact critique: 'no structure BETWEEN patterns'). An asymmetric/directed predictive-coding write is a concrete mechanism for laying a role->target DIRECTION into the substrate - the between-pattern association the nulls say is missing. Requires changing the substrate's coupling from symmetric to asymmetric, a non-trivial deviation from the current FHRR+MHN design.

### Compression-under-capacity consolidation (multi-epoch contrastive replay as abstraction)  [pdf:pam2-2026]
- AH-shape: offline-statistic — Clean as a fixed offline replay schedule with a fixed capacity budget - the bottleneck is a static architectural constraint, not a runtime metric-gated decision. What moves locally: atom/codebook embeddings under repeated contrastive descent. Apparent decision lives in the compression-forced energy minimum. FAILS if capacity is adaptively grown by reading a coverage metric at runtime (that is the 'Growing Codebook' Frame-B move, which must stay a fixed schedule, not a thermostat).
- maturity: plausible
- how it writes: Run the consolidation/replay objective UNDER a capacity bottleneck so the substrate cannot memorize all (role,target) pairs verbatim and is forced to compress across recurring role->target patterns. PAM2 shows this multi-epoch contrastive-under-compression regime (explicitly analogized to replay) writes transition-structure concepts that transfer to unseen items, where single-pass association does not. The 'write' is the compression pressure reshaping the landscape toward shared role-structure basins.
- relevance: Speaks to WHY structure may have failed to be written: if the current consolidation has no capacity pressure, it can store atoms as-is (the diagnosed behavior) and never abstract a role->target basin. It also connects to the OPEN Phase-3 thread (consolidation injects irreducible variance independent of landscape size, Reports 117/118) - capacity/compression is the lever PAM2 says forces abstraction. Caution: PAM2 validates by clustering quality, not a native basin readout.

### Range-shaped replay support (rectangular role x content) - prior-art, already partially closed here  [pdf:pam-2026]
- AH-shape: offline-statistic — Data-distribution shaping is anti-homunculus-clean: it changes the offline replay statistics, no runtime metric gate. The 'decision' lives in the marginal/range geometry of the replay buffer.
- maturity: speculative
- how it writes: Shape the replay/consolidation data distribution so role and content vary over a rectangular (independent-range) joint support, which (per the Dorrell/Whittington line cited in the kickoff seed, not in this corpus) forces the learner to factor role from content - writing role-discriminative structure as a side effect of the data geometry rather than an explicit term.
- relevance: Listed as a candidate in the kickoff seed (lines 80-84) BUT STATUS/Report 111 already record a range-shaped replay as 'closed as novelty-without-retrieval'. Flag: re-read Report 111 before re-proposing; do not treat as fresh. The supporting Dorrell/Whittington source is NOT in this corpus (link-only/absent) - not load-bearing until carded.

### Better-readout-space (feature-space autoassociation) - does NOT write structure  [arxiv:2402.10814]
- AH-shape: fails — Not a homunculus issue - it simply does not address the write problem. Marked 'fails' because as a candidate for OUR failure it is a non-mechanism: a cleaner readout cannot recover structure that was never written (kickoff seed 24-28, the exact reason GSBC is parked).
- maturity: proven-in-paper
- how it writes: Moves similarity computation into a contrastively-pretrained embedding space. It improves WHERE you read, not WHAT was written - it adds no role->target association the substrate didn't already have.
- relevance: Serves as the control/foil: it is the same class of move as GSBC (legibility upgrade), which the project has already correctly parked because the failure is FLAT/absence, not overlap. Including it makes explicit that readout-space papers in this cluster do not solve the write problem. Also: this source is mislabeled in the corpus (see cautions).

## Gaps
- No source in this cluster demonstrates a learned PC/JEPA/contrastive objective writing a role->target association INTO an FHRR/VSA superposition recovered by a native unbinding/MHN readout. PAM (Euclidean predictor + memory bank), tPC (asymmetric Hopfield), feature-space AM (contrastive encoder), and Recchia (fixed algebraic order-binding, no learning) each cover a different piece but none closes the loop the project needs. This is the central evidentiary gap and is precisely the kickoff seed's Stage-1 go/no-go.
- tPC's asymmetric-Hopfield-plus-whitening equivalence (the most substrate-relevant write mechanism) is unverified beyond the abstract - need the per-layer error term and update locality from full text, plus whether the whitening is compatible with FHRR's fixed random binding.
- The Dorrell/Whittington 'range-shapes-modularity' result that motivates the range-shaped-replay candidate is NOT in this corpus (no source_id); and the project already closed a range-shaped replay as novelty-without-retrieval (Report 111). Need either a carded source or a re-read of 111 before this candidate is actionable.
- No measurement exists of WHERE PAM's contrastive write would land a role-target on a NATIVE FHRR readout (rank_role / hit_role). The whole cluster argues structure CAN be written by these objectives in their own spaces; the missing experiment is a toy write-then-read on the actual substrate - which the kickoff seed names as Stage 1.
- PAM2's compression-forces-abstraction claim is the strongest 'consolidation-writes-transferable-structure' evidence but is validated by cluster quality at 29.4M params / corpus scale; there is no demonstration at the local-first MacBook-class scale the project requires, nor on an energy-landscape substrate.
